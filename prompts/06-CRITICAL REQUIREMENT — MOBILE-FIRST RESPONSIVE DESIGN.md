## CRITICAL REQUIREMENT — MOBILE-FIRST RESPONSIVE DESIGN

Smartphone is a first-class target platform, equally important to desktop and tablet.

Design and implement the application using a mobile-first responsive approach.

Required test viewports:
- Mobile: 360px, 390px and 430px.
- Tablet: 768px and 1024px.
- Desktop: 1280px and 1440px.

Requirements:
1. Every one of the five modules must be fully usable on smartphone.
2. No horizontal page overflow or clipped content.
3. Navigation must adapt intelligently: desktop sidebar, compact mobile navigation with accessible menu and/or bottom navigation.
4. Dashboard KPI cards must reflow into readable mobile layouts.
5. Charts must resize and retain readable labels and interactions.
6. Complex data tables must transform into mobile-friendly cards or dedicated responsive views.
7. Filters, search, forms, dialogs and actions must be touch-friendly.
8. AI Assistant must provide a native mobile chat experience.
9. IoT map must support full-screen mobile interaction.
10. Respect safe areas, keyboard behavior, orientation and accessible touch targets.
11. Test all five modules at all specified viewport sizes.
12. Do not hide important functionality on mobile merely to simplify implementation.

Mobile is not a secondary adaptation of desktop. It is a core product experience and must receive the same design and QA attention.
